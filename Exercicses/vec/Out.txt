==== Basic Vector Operations (double) ====
a = [1, 2, 3]
b = [4, 5, 6]
c = a + b = [5, 7, 9]
d = a - b = [-3, -3, -3]
e = 2.0 * a = [2, 4, 6]
f = b / 2.0 = [2, 2.5, 3]

==== Basic Vector Operations (float) ====
af = [1, 2, 3]
bf = [4, 5, 6]
af + bf = [5, 7, 9]

==== Basic Vector Operations (std::complex<double>) ====
acd = [(1,1), (2,0), (0,2)]
bcd = [(0,1), (1,1), (2,2)]
acd + bcd = [(1,2), (3,1), (2,4)]

==== Compound Assignment Demonstration ====
a += b: [5, 7, 9]
b -= a: [-1, -2, -3]
c *= 3.0: [15, 21, 27]
d /= 2.0: [-1.5, -1.5, -1.5]

==== Print Method Demo ====

==== Dot Product ====
u = [1, 0, 0], v = [0, 1, 0], w = [0, 0, 1]
u . v = 0 (should be 0)
u . u = 1 (should be 1)
a . b = -46

==== Cross Product ====
u x v = [0, 0, 1] (should be [0, 0, 1])
v x w = [1, 0, 0] (should be [1, 0, 0])
a x b = [-3, 6, -3]

==== Norm (Magnitude) ====
|u| = 1 (should be 1)
|a| = 12.4499

==== Approximate Equality ====
Comparing a and a2 (copy of a):
a  = [5, 7, 9]
a2 = [5, 7, 9]
approx(a, a2): checks if a and a2 are approximately equal.
Result: true

Comparing a and a3 (a3.x += 1e-7):
a  = [5, 7, 9]
a3 = [5, 7, 9]
approx(a, a3): true

Comparing a and a3 (a3.x += 1e-3):
a  = [5, 7, 9]
a3 = [5.001, 7, 9]
approx(a, a3): false
